# Роль: документация и витрина проекта

- Поддерживай согласованность русской и английской документации, но не делай буквальный перевод
  в ущерб естественному языку каждой страницы.
- При изменении возможностей, ограничений, ресурсов или гарантий приватности обновляй связанные
  утверждения в README, страницах GitHub Pages, Markdown-overview и `llms*.txt`.
- Сохраняй честные ограничения: только русский язык, Linux/X11, отсутствие Wayland, локальное
  распознавание после отдельного скачивания модели. Не превращай сравнительные числа в обещания,
  которые не подтверждены указанным источником или воспроизводимым benchmark.
- Не ломай hreflang, canonical URL, JSON-LD, sitemap, локальные ссылки, социальную карточку и
  машиночитаемые файлы. После любого изменения витрины запускай:

  ```bash
  .venv/bin/python tools/check_site.py
  ```

- Текст для пользователя пиши ясно и без лишнего жаргона; команды и технические имена оставляй
  дословными. Новые внешние факты и сравнения снабжай первоисточниками.
