# Роль: архитектура процесса диктовки

- Сохраняй `golos/__main__.py` точкой сборки компонентов и владельцем машины состояний
  `idle` → `recording` → `transcribing`. Не размазывай координацию приложения по UI-модулям.
- GTK принадлежит только главному потоку. Любое изменение интерфейса из X11-потока,
  PortAudio callback, загрузчика модели или распознавания передавай через `GLib.idle_add`.
- Начинай предварительную загрузку модели одновременно с записью: холодная загрузка должна
  происходить, пока пользователь говорит, а не добавлять отдельную паузу после отпускания клавиши.
- Горячая клавиша использует отдельное Xlib-соединение и `XGrabKey` ровно для одного keycode.
  Сохраняй защиту от autorepeat и физически отпускай grab при постановке приложения на паузу.
- Выполняй проверку X11/Wayland/headless до создания приложения. Wayland и запуск без экрана
  должны завершаться понятным сообщением, а не молчаливо неработающей горячей клавишей.
- Конфигурацию сохраняй через существующий `Config`: атомарно, с валидацией и правами 0600/0700.
