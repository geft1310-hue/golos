Golos — offline Russian voice dictation

Hold a key. Speak. Release. Punctuated text is already in your clipboard.

Install Source code on GitHub

What is Golos?

Golos (Russian for “voice”) is a free, open-source voice-typing application for Russian speakers using Linux. Hold the right Ctrl key, speak, and release it: the transcribed text appears in the clipboard, ready to paste anywhere with Ctrl+V. Recognition runs entirely on your computer. After the one-time model download, no internet connection is needed; speech is neither uploaded nor written to disk.

Golos uses GigaAM v3, a Russian speech-recognition model from SberDevices, through ONNX Runtime without PyTorch. The model emits punctuation, capital letters and numeric digits as part of recognition. Golos currently runs on Linux with X11, requires no GPU, account or subscription, and is licensed under MIT.

Why it exists

Russian voice typing often requires spoken commands such as “comma” and “full stop.” Google's documentation lists Russian punctuation commands, while Gboard's advanced automatic-punctuation feature officially lists several other languages but not Russian. Golos inserts punctuation without spoken commands.

Instead of:

привет как дела я сегодня буду в офисе часов в пять давай встретимся

Golos produces:

Привет, как дела? Я сегодня буду в офисе часов в 5. Давай встретимся.

Punctuation is not bolted on by a separate post-processor: the model emits it as part of recognition. GigaAM's published evaluation reports an F1 score of 84.5 for commas and 86.7 for full stops.

Sources: Google Docs voice typing, Gboard advanced voice typing, GigaAM evaluation.

Why not Whisper?

Whisper is the obvious local alternative, but large Whisper models can run slower than real time on a CPU. In an independent Russian ASR benchmark, whisper-large-v3-turbo had CPU RTF 1.02: slightly more than ten seconds of processing for ten seconds of speech. GigaAM v3 e2e-rnnt had RTF 0.047 in the same benchmark — more than 20 times faster, with comparable average accuracy on Russian. Golos chooses the smaller Russian-specialized model so interactive dictation works without a GPU.

Source: independent benchmark of Russian ASR models (article in Russian).

Install on Linux

For Debian, Ubuntu, Linux Mint and related distributions, open a terminal and run:

git clone https://github.com/geft1310-hue/golos.git
cd golos
./install.sh

The installer checks what is missing rather than blindly reinstalling everything. It downloads the 217 MB model once and can add Golos to your login session.

./run.sh

A microphone icon appears in the system tray. Golos is ready.

How to use it

  1. Place the cursor where you want the text.
  2. Hold the right Ctrl key. A small overlay shows ● Запись (“Recording”), a live level meter and a timer.
  3. Speak Russian.
  4. Release the key. The overlay shows Распознаю… (“Recognizing”), followed by ✓ Скопировано (“Copied”).
  5. Press Ctrl+V.

The clipboard approach works in any application with a text field: browser, email, messenger or editor. Long speech is split at natural pauses and joined again. The hotkey, microphone, model-unload timer and optional clipboard clearing are configurable.

Speed, memory and accuracy

Our measurements on deliberately old hardware

Everything below was measured on an Intel i7-2640M, a two-core laptop CPU from 2011, with 8 GB of RAM. The scripts are in the bench/ directory, so every measurement can be reproduced.

Recognition speedRTF 0.31 — ten seconds of speech in 3.1 seconds
Idle memoryabout 65 MB
Memory with model loadedabout 304 MB
Memory returned after unload238 MB out of 273 MB
Cold model load1.7–1.9 seconds
Disk space217 MB
Network connections while runningzero

The microphone is closed until the key is pressed, and the model unloads after a few idle minutes. At the next press, loading starts at the same time as recording — while you are speaking.

Accuracy measured by other people

WER is the percentage of words recognized incorrectly; lower is better. In the model vendor's ten-set Russian evaluation, GigaAM v3 e2e-rnnt (the Golos default) averaged 11.2, versus 21.0 for Whisper-large-v3. In a separate six-set benchmark, GigaAM scored 10.38 and Whisper-large-v3-turbo 13.25.

Where Whisper wins: results were close for clean, close-microphone speech, but Whisper beat GigaAM by 6–7 points on noisy, reverberant recordings. Golos is designed for a microphone in front of the speaker, not a phone across a noisy room. Choose Whisper when audio quality is poor.

Sources: GigaAM vendor evaluation, independent six-dataset benchmark.

Privacy: what Golos sees and never does

The privacy claims are stated as testable behavior, including the uncomfortable detail most global-hotkey applications leave undocumented.

Testable propertyVerification
No network access during dictationss -tunp against the live process: zero network connections
Speech is never written to disk; the PCM buffer is zeroed after recognitionbench/test_privacy.py
Recognized text is not stored; recent phrases exist only in RAMdisk-wide marker search found nothing
No request for the clipboard manager to persist text to diskGtk.Clipboard.set_text() without store()
Logs contain text length, never the textentries such as recognized characters: 43
Downloaded Python code is not executed; the model is ONNXmodel files are pinned to a commit and verified with SHA-256

The one network exception: the model must be downloaded once. A separate program, tools/fetch_models.py, does that during installation or when the user deliberately selects another model variant. The dictation process itself contains no networking code.

What the hotkey can see

Golos uses the narrowest X11 mechanism available: XGrabKey for one specific keycode, not a global listener for every key you type.

While the hotkey is held, other key events are delivered to the grabbing application and do not reach the focused window. Golos discards every unrelated event on the first line of its handler: it is not stored, inspected or logged, even in debug mode.

In practice, typing does not work while the right Ctrl key is held; normal behavior returns immediately after release. The behavior is reproducible with bench/test_grab_exposure.py.

Limitations, stated plainly

  • Russian only. GigaAM v3 is specialized for Russian; that specialization is why it can be small and fast on its one language.
  • Linux with X11 is required. There is currently no universal equivalent for the same “hold one global key” interaction across all Wayland environments. Golos detects Wayland at startup and explains the limitation. On Ubuntu and similar systems, choose an Xorg session from the gear menu on the login screen.
  • Windows and Android are not released. They are planned, but the current application is Linux/X11 only.
  • Noise and reverberation. Whisper may be more accurate on poor recordings.

Frequently asked questions

Does Russian speech recognition need an internet connection?

Not with Golos. Internet is needed once to download the 217 MB model. Recognition then runs entirely on the computer, and the dictation process opens no network connections.

How do I type Russian by voice on Linux?

Install Golos, put the cursor in any text field, hold right Ctrl, speak Russian, release the key and press Ctrl+V. The punctuated text is pasted into the current application.

Does Golos add Russian punctuation automatically?

Yes. GigaAM v3 emits punctuation, capital letters and numeric digits as part of recognition. You do not need to say “comma” or “full stop.”

Is Golos free?

Yes. It is open source under the MIT license, with no registration, subscription or word limit.

Does Golos work on Wayland?

The current version does not; it requires X11/Xorg. It relies on an X11 mechanism for narrowly grabbing one push-to-talk key, and there is no universal equivalent across all Wayland desktops.

Which languages does Golos support?

Russian only. It deliberately uses a Russian-specialized model rather than a multilingual one.

Does it need a GPU?

No. Inference runs on the CPU. The published measurements use a two-core laptop CPU from 2011.

How is Golos different from Wispr Flow and Superwhisper?

Wispr Flow requires internet access and always transcribes in the cloud. Superwhisper supports local models but does not officially support Linux. Golos is free, local and designed for Linux/X11, but supports only Russian and has fewer features.

Why not use Whisper?

Whisper is a good choice for many languages, GPU systems and noisy recordings. Golos uses GigaAM because this Russian-specialized model is substantially faster on a CPU and suits interactive dictation.

Is recorded speech stored?

No. Audio lives only in RAM, and its buffer is zeroed after recognition. No recording file is left on disk, and recognized text is not persisted either.

Can I change the hotkey?

Yes. The settings also let you select the microphone and the model-unload timeout.

How much disk space and RAM does it use?

The model uses 217 MB of disk space. Golos uses about 65 MB of RAM while idle and about 304 MB with the model loaded.
