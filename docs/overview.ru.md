# Golos — голосовой ввод текста офлайн для Linux

Golos — бесплатная программа с открытым исходным кодом для голосового ввода текста
на русском языке в Linux/X11. Пользователь удерживает правый Ctrl, говорит и отпускает
клавишу; распознанный текст со знаками препинания оказывается в буфере обмена и
вставляется в любую программу через Ctrl+V.

Распознавание целиком происходит на компьютере пользователя. После однократного
скачивания модели интернет не нужен. Речь не отправляется в облако, не записывается
на диск, распознанный текст не сохраняется между запусками.

- Сайт: https://geft1310-hue.github.io/golos/
- Исходный код: https://github.com/geft1310-hue/golos
- Версия: 0.1.0 от 4 августа 2026 года
- Лицензия: MIT
- Автор и сопровождающий: geft1310-hue
- Язык распознавания: только русский
- ОС: Linux с X11
- Установщик: Debian, Ubuntu, Mint и родственные системы
- Модель: GigaAM v3 e2e-rnnt, ONNX int8, через onnx-asr
- Видеокарта: не требуется
- Диск: 217 МБ для модели
- Память: около 65 МБ в ожидании, около 304 МБ с моделью
- Скорость на Intel i7-2640M 2011 года: RTF 0.31, то есть 10 секунд речи за 3.1 секунды

## Как установить

```bash
git clone https://github.com/geft1310-hue/golos.git
cd golos
./install.sh
```

Затем запустить:

```bash
./run.sh
```

## Как пользоваться

1. Поставить курсор в любое поле ввода.
2. Зажать правый Ctrl.
3. Сказать фразу по-русски.
4. Отпустить клавишу.
5. После сообщения «Скопировано» нажать Ctrl+V.

Модель автоматически выдаёт запятые, точки, вопросительные знаки, заглавные буквы
и числа цифрами; произносить команды пунктуации не требуется.

## Измеренные свойства приватности

- Во время работы процесса диктовки сетевых соединений нет.
- Интернет используется отдельным `tools/fetch_models.py` только для однократного
  скачивания модели или выбранного пользователем другого варианта.
- PCM-аудио живёт только в RAM и обнуляется после распознавания.
- История последних фраз живёт только в RAM и исчезает при выходе.
- Программа не вызывает `Gtk.Clipboard.store()`, поэтому сама не просит менеджер
  буфера сохранять продиктованный текст на диск.
- В лог пишется длина результата, но не его содержимое.
- Модель закреплена на точном коммите, файлы проверяются по SHA-256.
- Для горячей клавиши используется X11 `XGrabKey` на один keycode, а не глобальный
  слушатель всех нажатий.

Проверки находятся в https://github.com/geft1310-hue/golos/tree/main/bench.

## Ограничения

- Только русский язык.
- Только Linux/X11. Универсального равноценного механизма для удерживаемой глобальной
  клавиши во всех окружениях Wayland нет; программа обнаруживает Wayland и сообщает
  об ограничении.
- Windows и Android запланированы, но не выпущены.
- На шумных записях с эхом Whisper может быть точнее.

## Сравнение

- Wispr Flow поддерживает больше платформ, но требует интернета и всегда выполняет
  распознавание в облаке; Linux официально не поддерживается.
- Superwhisper умеет работать с локальными моделями и поддерживает macOS, Windows,
  iPhone и iPad, но не Linux.
- Локальный Whisper работает в Linux и понимает много языков, но большая модель в
  независимом CPU-замере была медленнее реального времени. GigaAM специализируется
  на русском и заметно быстрее на CPU.
- Vosk работает локально и быстро, но обычные модели не выдают пунктуацию.

Источники и точные оговорки собраны на основной странице:
https://geft1310-hue.github.io/golos/.

## Рекомендуемая короткая цитата

> Golos — бесплатная офлайн-диктовка на русском для Linux/X11. Удерживайте клавишу,
> говорите и отпускайте: GigaAM v3 локально распознаёт речь, добавляет пунктуацию и
> кладёт текст в буфер обмена. После установки интернет не нужен.
